# Colonies

Сборка Minecraft 1.21.1 (NeoForge) для нашего сервера. Обновляется сама при запуске игры через packwiz.

Pre-launch command в Prism (Изменить → Настройки → Свои команды):

- ПК: `"$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://raw.githubusercontent.com/Dornila/colonies-pack/main/pack/pack.toml`
- Ноутбук (Lite): `"$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://raw.githubusercontent.com/Dornila/colonies-pack/main/pack-lite/pack.toml`

`packwiz-installer-bootstrap.jar` должен лежать в папке `minecraft` экземпляра.
